 Description

Ang akong Java program ginagamit sa pag-sort sa mga number gamit ang tulo ka sorting algorithms ang Bubble Sort, Selection Sort, ug Insertion Sort. Ang mga ang mga number gikan sa pinakagamay hangtod sa pinakadako.

Sorting Algorithms

1. Bubble Sort

Ang Bubble Sort magkumpara sa duha ka gatapad nga number. Kung mas dako ang una kaysa ikaduha, mag-ilis sila og pwesto. Balik-balikon ni hangtod ma arrange ang tanan nga number.

2. Selection Sort

Ang Selection Sort mangita sa pinakagamay nga numero ug ibutang ni sa unang pwesto. Padayon kini sa pagpangita sa sunod nga pinakagamay nga number hangtod mahuman ang pag-sort.

3. Insertion Sort

Ang Insertion Sort magkuha og usa ka number ug ibutang ni sa sakto nga pwesto padulong sa mga numero nga na sort na. Balik-balikon ni hangtod ma arrange ang tanan nga numero.

Differences Between the Algorithms

Ang Bubble Sort magkumpara sa gatapad nga numero, ang Selection Sort mangita sa pinakagamay nga numero, ug ang Insertion Sort magbutang sa numero sa sakto nga pwesto. Lahi ilang pamaagi pero parehas ra ilang goal nga mahan-ay ang mga numero gikan sa pinakagamay hangtod sa pinakadako.

Reflection Questions

1. How does each sorting algorithm arrange numbers?

Ang Bubble Sort magkumpara sa magtapad nga numero. Ang Selection Sort mangita sa pinakagamay nga numero ug ibutang sa unahan. Ang Insertion Sort magbutang sa numero sa sakto nga pwesto. Lahi ilang proseso pero parehas ra ilang tumong.

2. Which algorithm is easiest to understand and implement?

Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton kay magkumpara ra kini sa duha ka magtapad nga numero ug mag-ilis sa ilang pwesto kung kinahanglan.

3. Which algorithm performs better if numbers are already sorted?

Para nako, ang Insertion Sort ang mas maayo kung sorted na daan ang mga numero kay dili na kinahanglan nga magbalhin-balhin og daghang numero.

4. What happens if you add more numbers?

Kung modaghan ang mga numero sa array, modaghan pud ang trabaho sa sorting algorithms. Mas daghan silang ikumpara ug mas dugay mahuman ang pag-sort.

5. Why is it important to understand different sorting algorithms?

Importante nga makasabot ta sa lain-laing sorting algorithms aron makahibalo ta kung unsang pamaagi ang mas angay gamiton. Makatabang kini nato sa paghimo og mas maayong programa isip future programmer.
